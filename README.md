# FRAMEFORGE Video

**FRAMEFORGE Video** — отдельный видеоредактор экосистемы FRAMEFORGE.

## Preview 0.1.0

В репозитории находится первый интерактивный прототип интерфейса и монтажной логики.

### Уже реализовано
- Единый тёмный сине-графитовый стиль FRAMEFORGE.
- Рабочая область: медиатека, предпросмотр, инспектор свойств и временная шкала.
- Импорт видео и аудио с локального устройства.
- Добавление клипов на временную шкалу, выбор и перемещение клипов.
- Несколько видео- и аудиодорожек.
- Позиция, длительность, точка входа и громкость клипа в инспекторе.
- Разделение клипа по позиции плейхеда и удаление.
- Текстовые слои.
- Воспроизведение предпросмотра и горячие клавиши Space, Delete, Ctrl+S, Ctrl+Z.
- Сохранение структуры проекта в JSON-файле .ffvideo.
- Базовый экспериментальный экспорт WebM через MediaRecorder.
- Локальная обработка импортированных файлов; отправка файлов на сервер не требуется.

### Запуск
Откройте `index.html` в современном браузере (рекомендуется актуальный Chrome или Edge). Для некоторых браузерных API может потребоваться запуск через локальный HTTP-сервер.

## Ограничения Preview 0.1.0
Это ранний прототип, а не готовый монтажный продукт:
- Проектный файл пока сохраняет структуру монтажа, но не упаковывает исходные медиафайлы. При повторном открытии потребуется повторный импорт исходников.
- Экспорт пока экспериментальный WebM. MP4/H.264, полноценный аудиомикс, переходы, эффекты, цветокоррекция и аппаратное ускорение ещё не реализованы.
- Синхронизация нескольких дорожек и точность предпросмотра требуют дальнейшей разработки.
- Поддерживаемые кодеки зависят от браузера и операционной системы.

## Roadmap
1. Надёжная модель проекта и восстановление ссылок на медиа.
2. Полноценный многодорожечный таймлайн: trim, ripple delete, snapping, split, группировка.
3. Аудиомикшер, waveform и синхронизация.
4. Текстовые титры, переходы, фильтры и keyframes.
5. Экспорт MP4/H.264 и WebM через интегрированный FFmpeg.
6. Настройки проекта, autosave, undo/redo и управление горячими клавишами.
7. Упаковка в автономное настольное приложение Windows.

FRAMEFORGE Video должен оставаться самостоятельным продуктом без обязательной подписки, водяных знаков и искусственной блокировки базовых функций.
